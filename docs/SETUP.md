# Development Setup

## Requirements

- Node.js 22 LTS
- npm (or pnpm)
- Git
- VS Code

## Clone Repository

git clone https://github.com/<username>/remradar.git

cd remradar

## Install

npm install

## Run

npm run dev

## Build

npm run build

## Lint

npm run lint

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion
- GSAP
- Sanity CMS
- Vercel
