# Logo Guidelines

## Purpose

Defines the official usage of the REM logo.

---

# Logo Versions

Primary Logo

Default usage.

Secondary Logo

Alternative layouts.

Monochrome Logo

Used when colour is unavailable.

Icon

Used for applications and favicons.

---

# Minimum Size

The logo should never be displayed below the approved minimum size.

---

# Clear Space

Maintain sufficient spacing around the logo.

No text or graphics should enter the protected area.

---

# Incorrect Usage

Do not:

- Stretch the logo.
- Rotate the logo.
- Change colours.
- Add shadows.
- Add outlines.
- Distort proportions.
- Overlay on unreadable backgrounds.

---

# File Formats

SVG

Preferred for digital.

PNG

Used where SVG is unsupported.

ICO

Favicon.

---

# Ownership

The REM logo is protected intellectual property.
