# ASSETS

## Purpose

This document defines how static assets are organised within RADARCharts.

---

# Asset Categories

- Logos
- Icons
- Fonts
- Illustrations
- Patterns
- SVG Graphics
- Documents
- Downloads

---

# Folder Structure

public/

images/

videos/

icons/

logos/

fonts/

---

# Naming Convention

Use lowercase.

Use hyphens.

Good

hero-homepage.webp

artist-card.svg

brand-logo.svg

Avoid

HeroImage.PNG

logoFINAL2.svg

---

# Versioning

Replace old assets rather than creating:

logo-final-final.svg

logo-new2.svg

Use proper version control instead.

---

# Optimisation

- Minify SVGs.
- Compress PNG/JPG/WebP.
- Remove unused assets.
- Keep assets organised.

---

# Licensing

Only use assets that are:

- Created by REM
- Licensed
- Public Domain
- Properly attributed
