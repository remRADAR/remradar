# IMAGES

## Purpose

This document defines image standards for RADARCharts by REM.

It ensures consistency, quality, and performance across the platform.

---

# Image Categories

- Hero Images
- Featured Images
- Artist Photos
- Album Covers
- Event Banners
- Magazine Covers
- Thumbnails
- Icons
- Background Images

---

# File Formats

Preferred:
- WebP
- SVG (logos & icons)
- PNG (transparent assets)
- JPG (photography where appropriate)

Avoid:
- BMP
- TIFF
- GIF (unless required)

---

# Image Sizes

## Hero
1920×1080+

## Featured
1200×630

## Thumbnails
600×600

## Artist Images
1000×1000

---

# Optimisation

- Compress before upload.
- Serve responsive images.
- Lazy-load non-critical images.
- Keep file sizes as small as possible without visible quality loss.

---

# Accessibility

Every image must include:

- Alt text
- Descriptive filenames

Example:

artist-burna-boy-live.webp

Avoid:

IMG_2489.png
