# REMRADAR Media Standards

## Purpose

This document defines how every media asset used across REMRADAR should be prepared, named, optimized and displayed.

---

# Image Formats

Preferred

- AVIF
- WebP

Fallback

- JPG
- PNG

Never upload BMP or TIFF.

---

# Featured Images

Aspect Ratio

16:9

Used For

- Homepage
- Articles
- Categories
- Search
- Social Sharing

---

# Editorial Images

Aspect Ratio

1:1

Used For

- Inside Articles
- Galleries
- Artist Photos

---

# Magazine Covers

Aspect Ratio

4:5

---

# Artist Images

Preferred

Square

High Resolution

Neutral Background

---

# Logo Assets

Store as

SVG

PNG (Transparent)

White Version

Black Version

Silver Version

---

# Background Assets

Preferred

CSS Gradients

SVG Patterns

Minimal Texture

Avoid heavy image backgrounds.

---

# Video

Only one hosted video:

Intro / Welcome Animation

Preferred Format

WebM

Fallback

MP4

---

# Icons

SVG

Use Lucide icons for interface elements.

---

# Naming Convention

artist-burna-boy.webp

cover-top25-2025.webp

magazine-episode-01.webp

hero-homepage.avif

---

# Optimization

Maximum Upload Size

5MB

Target Delivery Size

Under 300KB where practical

---

# Accessibility

Every image requires:

- Alt text
- Caption (if applicable)
- Credit (if applicable)
