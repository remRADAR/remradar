# VIDEOS

## Purpose

This document defines the video strategy for RADARCharts by REM.

The platform is designed to minimise storage costs and maximise performance by embedding external video content whenever possible.

---

# Video Strategy

RADARCharts does not host video files directly except where necessary for the user experience.

## Directly Hosted

Only the following may be hosted by the platform:

- Welcome Animation
- Future brand intro (if required)

These assets should be highly optimised and kept as lightweight as possible.

---

# Embedded Videos

The following should always be embedded:

- Music Videos
- Artist Interviews
- Live Sessions
- XCAPE Event Highlights
- Podcasts
- Magazine Features
- Press Conferences
- Behind-the-scenes content

The application should embed videos from supported platforms rather than storing them locally.

---

# Performance

- Never upload large video files to the repository.
- Lazy-load embedded videos.
- Display thumbnails until playback begins.
- Optimise the Welcome Animation for fast loading.

---

# Welcome Animation

The Welcome Animation is part of the RADARCharts experience.

Requirements:

- Lightweight
- Fast loading
- Responsive
- Accessible
- Skippable if necessary

This is the only video asset intended to ship with the application.

---

# Future Considerations

If self-hosted video becomes necessary in the future, it should be introduced only after evaluating storage costs, CDN requirements, and streaming performance.
